Every frame above is one photograph under one interpolating filter. Hover any of them to run it live. --flir-photo-filter-rest and --flir-photo-filter-reveal exist only so that is possible: a filter transition interpolates when both values carry the same functions in the same order, and -corbijn (grayscale first) to -native (contrast first) does not — it lands on the end value on frame one. The twins render identically to those two; saturate(1) and grayscale(0) are identity operations, present only to match the shape. Keep all four functions, in order, in both.

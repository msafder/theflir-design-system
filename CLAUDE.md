# Project rules

## Band name
The band is always written **THE FLIR** — never "FLIR" on its own. "FLIR" alone
is an unrelated business (thermal imaging hardware) and must never appear as the
mark, in copy, in file names, in alt text, or in a logo lockup.

- Correct: `THE FLIR`, `THE FLIR · MMXXVI`
- Wrong: `FLIR`, `the flir` (except in URLs: theflir.com, @theflir)
- Catalogue prefix is `suture8-` (e.g. `suture8-01`), not `FLIR-`. This is
  the number the 2002 CD actually shipped with; the earlier `TF-` scheme was a
  system invention and is retired. Merch runs `suture8-M01`.

## Label separation
- The label is never named in this system or on theflir.com. No "EYELINER
  MEDIA" in copy, credits, components, templates, metadata or comments.
- Store links are functional URLs only, labelled "Shop" or "Merch". The
  storefront belongs to the label's own system, outside this repo.

## References
- Visual reference: the Official Recoil website (recoil.co.uk / "Shunt") —
  dark, textural, grimy photographic fields with a clean typographic layer
  sitting over them. Clean type, dirty image.
- Sound: trip hop, shoegaze, goth, ethereal. Cocteau Twins, Depeche Mode,
  Massive Attack, The Smiths.
- Design system lives in this project; direction is "Thermal Register" (1c).

## Design system rules
- Components use tokens only. Any raw value must be documented as a deviation
  in the component's `.prompt.md` and on its preview card.
- Dark ("ink") is the default theme. Light ("chalk") is the exception.
